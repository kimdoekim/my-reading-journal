# My Reading Journal

간단한 독서 기록·리뷰 웹 애플리케이션입니다.  
React + TailwindCSS 프론트엔드와 Spring Boot 백엔드로 구성되어 있으며,  
독서 세션 타이머, 책 메타데이터 검색, CRUD 기능을 제공합니다.

---

## 🚀 기능 (Features)

- **독서 리뷰 CRUD**  
  - 책 제목·저자·커버 이미지 검색 후 리뷰 작성  
  - 리뷰 목록 / 상세 / 수정 / 삭제  
- **독서 기록(세션) CRUD**  
  - 타이머 기능으로 독서 시작/종료 시간 자동 기록  
  - 페이지 수, 메모 추가  
  - 기록 목록 / 상세 / 수정 / 삭제  
- **로컬 타임존 & 한국어 시간 포맷**  
- **반응형 디자인** (모바일 ↔ 데스크톱)  
- **토스트 알림**(react-hot-toast)  

---

## 🛠️ 기술 스택 (Tech Stack)

| 역할       | 프레임워크·라이브러리         |
|------------|-----------------------------|
| Frontend   | React, React Router, Tailwind CSS, react-hot-toast |
| Backend    | Spring Boot, Spring Data JPA, MySQL |
| 기타       | Axios, Lombok |
